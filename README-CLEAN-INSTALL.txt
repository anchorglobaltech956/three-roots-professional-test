THREE ROOTS CLEAN HOSTINGER INSTALL

1. BACK UP current public_html before deleting anything.
2. In public_html, remove the OLD WEBSITE FILES after the backup.
3. Keep Hostinger system folders such as .well-known if present.
4. Upload Three-Roots-Clean-Hostinger-Production.zip into public_html.
5. Extract the ZIP directly into public_html.
6. Confirm index.html is directly inside public_html (not inside another folder).
7. Test the live website with Ctrl+F5 / private browser window.

This package intentionally excludes the old bird/breed gallery media and video.
